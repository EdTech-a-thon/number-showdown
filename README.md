# Number Showdown

A fast, team-based higher-or-lower number guessing game for the classroom. Built with Vite and Svelte 5.

## Features

- Choose a preset range or enter any custom whole-number range
- Name two to six teams and pick playful mascots
- Take turns guessing with clear higher/lower feedback
- Watch the possible-number span shrink after every guess
- Play repeated rounds with persistent scores
- Responsive, accessible interface for classroom displays and phones

## Development

```bash
npm install
npm run dev
```

Run checks and create a production build:

```bash
npm run check
npm run build
```

Cloudflare Web Analytics is enabled in production when `VITE_CF_BEACON` is set.
